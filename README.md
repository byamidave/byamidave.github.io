# By Ami Dave

A minimalist photography website.

## Replace the placeholder images

Put your own photographs inside the `images` folder and either:

- rename them to `hero.jpg`, `photo-1.jpg`, etc. and update the filenames in `index.html`, or
- overwrite the placeholder SVG files using the same filenames.

## Publish with GitHub Pages

Create a public repository named `byamidave.github.io`, upload all files in this folder, and the site will publish at:

https://byamidave.github.io
